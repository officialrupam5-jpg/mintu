# Mintu and Sabita wedding invitation

A static Assamese wedding invitation site. It has no build step or package dependencies.

## Run locally

Open the folder in VS Code and use the Live Server extension to serve `index.html`.
Opening the file directly may prevent the browser from playing the songs.

## Publish with GitHub Pages

1. Create a GitHub repository and upload all of these files and the `assets` folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Open the published URL shown on the Pages settings screen.

The site uses relative paths, so the photo and songs are served from the repository.
Browsers may block audio autoplay; if so, tap the heart once to allow playback.
